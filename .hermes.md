# Foodie

Plataforma própria de delivery multirrestaurante (marca Foodie), em `platform/`: API
**Java 21 / Spring Boot 3.5** (Flyway, banco MariaDB próprio) + site **Next.js**. Atende
os quatro papéis (cliente, restaurante, administração e entregador) no mesmo app — o papel
é definido no login.

2026-09-25 e, em 2026-10-06, de todo o histórico do Git, com a mudança do repositório para a
organização `axyonsoftwarehouse` — auditoria em `docs/AUDITORIA_LEGADO_2026-10-01.md`.

## Como rodar (platform/)

```bat
docker compose up -d db                         :: MariaDB local (127.0.0.1:3307)
docker compose --profile java up -d --build     :: API Java (4001); o Flyway migra na subida
pnpm install
pnpm --filter @foodie/api seed                   :: dados de demonstração (exige DEMO_PASSWORD)
pnpm dev                                        :: site Next (http://127.0.0.1:3001)

pnpm verify                                     :: testes TS + Java + tipos + build
VERIFY_INTEGRATION=1 pnpm verify                :: banco efêmero + E2E dos quatro papéis
pnpm load                                       :: teste de carga contra a API
```

Detalhes em `platform/README.md`; homologação em `platform/deploy/`.
