# Foodie

Sistema de delivery multirrestaurante: app do cliente, app do restaurante, app do
entregador (Flutter), painel administrativo + API (Laravel) e site (Next.js). Roda
tudo local, com MariaDB e nginx portáteis em `_local_server`.

A base é o script comercial **StackFood Multi Restaurant v9.0**, sendo rebatizado
como Foodie.

## Como rodar

```bat
iniciar-admin.bat    :: MariaDB + "php artisan serve" em 127.0.0.1:8000 (abre /login/admin)
parar-admin.bat      :: mata o php e desliga o MariaDB

build-web.bat        :: flutter build web nos 3 apps
iniciar-web.bat      :: MariaDB + 4 workers php-cgi + nginx :8000 + serve-web.js
                     ::   -> 8081 cliente, 8082 restaurante, 8083 entregador
parar-web.bat        :: derruba tudo

web/  npm run dev | npm run build | npm start     # Next.js na 3000
```
